# 커버리지 게이트(jacocoTestCoverageVerification) 제외 목록 — 정본.
#
# 이 파일이 생긴 이유(실측): 같은 목록이 build.gradle.kts 와 shared-common/build.gradle.kts 에
# 따로 적혀 있었고 갈라졌다. 루트는 어댑터·config·util 22개 패턴을 제외하는데 shared-common 은
# `**/common/pdf/**` 하나만 제외했다. shared-common 은 독립 빌드라 루트 subprojects {} 를
# 상속받지 않으므로, 한쪽을 고쳐도 다른 쪽은 그대로 남는다.
#
# 갈라진 결과는 "더 엄격"이 아니라 **꺼진 게이트**였다. shared-common 은 LINE 81% 로 90% 문턱을
# 넘지 못한 채였고, `test` 는 `jacocoTestCoverageVerification` 에 의존하지 않으므로
# `:shared-common:test` 는 계속 초록불이었다. 문턱을 못 넘는 게이트는 아무도 안 켜게 된다.
#
# 규칙:
#   - 한 줄에 Ant 패턴 하나. `#` 뒤는 주석. 빈 줄은 무시.
#   - 두 빌드가 **이 파일만** 읽는다. 빌드 스크립트에 패턴을 직접 적으면 드리프트가 다시 시작된다
#     (scripts/harness/test/coverage-excludes-gate.test.mjs 가 막는다).
#   - 여기서 뺀 코드는 "검증 안 함"이 아니라 "다른 데서 검증함"이다. persistence 어댑터는
#     TestContainers IT, 웹 어댑터는 MockMvc 슬라이스가 담당한다.
